# Sets de preguntas

- Existirán 5 sets de preguntas JSON con toda la información necesaria para cada una de ellas

- Para los Readings: un set inicial de 50 Readings con sus propias preguntas y respuestas sobre el texto

- Para la gramática: para las preguntas de completado de gramática, set de 200 preguntas 

- Para los writings: set de 200 temas para escribir un writing

- Para traducción: 800 frases del español al inglés con traducciones de referencia, en 25 bloques de 32 frases
