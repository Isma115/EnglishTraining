# Vista de Vocabulary

- Tendrá un sistema de memorizado de "repetición espaciada"

- Se irán cargando varias palabras de vocabulario y existirá el algoritmo de repetición espaciada por tarjetas

- El usuario podrá escribir el significado en Español o en inglés dada una palabra inglés-español y el algoritmo se irá ajustando según como el usuario vaya avanzando en la memorización del vocabulario

- Podrá elegir en esta misma interfaz el usuario la dificultad del set de palabras

- Las palabras se podrán cargar del set de palabras json de 20.000 palabras inglés-español
